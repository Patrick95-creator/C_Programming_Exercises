# 02 - Text Output and Arithmetic in C

This folder contains my solutions for the second exercise sheet of the course **"Introduction to Programming in C (WS 24/25)"**.

## Topics covered

The main focus of this exercise is learning how to produce formatted output in C and perform basic arithmetic operations.

Key concepts practiced in this exercise include:

* using `printf` for formatted text output
* escape sequences such as `\n`, `\t`, and `\\`
* compiling C programs with `gcc`
* integer arithmetic and division
* the modulo operator `%`
* formatting numbers with different format specifiers (`%d`, `%f`, `%i`, etc.)
* working with different data types (`int`, `unsigned`, `double`)
* debugging syntax and compilation errors
* printing memory addresses using pointer format specifiers

## Learning goals

After completing this exercise I practiced:

* writing simple C programs
* formatting program output
* understanding integer vs. floating-point calculations
* interpreting compiler errors and warnings
* working with variables and arithmetic expressions
* printing memory addresses of variables
