# Exercise 01 – Text Output and Calculations

Course: **Introduction to Programming in C (WS 24/25)**

## Topics covered

This exercise focuses on the basic concepts of text output, arithmetic operations, and simple debugging in C programs.

Main topics:

* Using `printf` for formatted output
* Escape sequences (`\n`, `\t`, `\"`, `\\`)
* Compiling C programs with `gcc`
* Integer division and floating-point division
* Basic arithmetic operations in C
* Reading and understanding compiler errors
* Correcting syntax and semantic errors in programs
* Formatting numeric output with format specifiers

---

## Learning objectives

After completing this exercise I learned how to:

* compile C programs using `gcc`
* understand the structure of a simple C program (`main`, `stdio.h`, return values)
* use `printf` for formatted output
* understand how integer and floating-point calculations differ
* interpret compiler warnings and error messages
* debug simple C programs
* format output with different specifiers (`%d`, `%f`, `%i`, etc.)
